# Supbyte Sound Booster — Browser Extension

A browser extension that enhances your audio experience by allowing volume boosting up to 600%, custom EQ profiles (Flat, Voice, Bass, Treble), output device selection, and per-site audio settings. Features real-time frequency analyzer visualization and advanced safety controls for a superior listening experience on any website. Created by Supbyte.

- 🔊 Volume boost up to **600%**
- 🎛️ Custom EQ profiles: Flat, Voice, Bass, Treble
